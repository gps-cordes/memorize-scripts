# Memorize Scripts

This react webapp facilitates memorizing text.

It comes preloaded with snippets of scenes from W.S. Gilbert's "Patience"

## Strategy

By advancing the "redaction" level, more letters of the chosen text are replaced with "-".

## Running

`npm run dev` starts a local server and will display a QR code to the address on your local network, useful for mobile devices.

`npm run build` will create an html file with all the preloaded scripts. This can be loaded by any modern browser or sent to devices as needed.
